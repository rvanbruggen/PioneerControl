# Pioneer Amp Input Sources

Edit this file to configure which input sources appear in the app by default
for each zone. When a family member opens the app for the first time, they
will see only these inputs — no manual configuration needed on their device.

Individual users can still override these defaults via the Settings screen
(the gear icon), and their personal choices are saved on their own device.
Resetting settings will return to these defaults.

Input names must match exactly (case-sensitive). Available names per zone:

**Main Zone:** BD, DVD, SAT/CBL, TV, iPod/USB, CD, Tuner, BT Audio, Network,
Internet Radio, Media Server, Spotify, HDMI 1, HDMI 2, HDMI 3, HDMI 4,
HDMI 5, HDMI 6, HDMI 7, Phono

**Zone 2 / HD Zone:** BD, DVD, SAT/CBL, TV, iPod/USB, CD, Tuner, BT Audio, Network
